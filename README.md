# MYSKME Lab · 原型试验田

狼先生工作室的小游戏原型验证区。每个原型都是**单文件、离线可玩、手机友好**。

在线试玩：https://myskme.github.io/myskme-lab/（开 Pages 后生效）

## 原型一览

| 原型 | 类型 | 版本 | 说明 |
|---|---|---|---|
| [星尘打捞](./xingchen-dalao/) | 休闲 | v0.1 | 挖金矿式单屏小游戏：摇摆钩子，点击放钩，60 秒捞分 |
| [守夜灯火](./shouye-denghuo/) | 叙事 | v0.5 | 谷地守夜人题材：夜观异象、判词推理、求签、雾中呓语 |

## 目录约定

- 每个原型一个目录，入口为该目录下的 `index.html`
- 新版本直接覆盖 `index.html`，旧版本归档进 `archive/`（如需保留）
